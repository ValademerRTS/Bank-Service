# VBank

Учебный банковский сервис на Flask с веб-интерфейсом в жёлто-чёрном стиле. Можно открыть счёт, войти, пополнить баланс, снять деньги, перевести их другому клиенту и посмотреть историю операций.

## Возможности

- Регистрация и вход по имени и паролю
- Пополнение счёта
- Снятие денег (нужен пароль)
- Переводы между клиентами по имени (нужен пароль отправителя)
- История последних 10 операций
- Адаптивный интерфейс: работает и на компьютере, и на телефоне

## Запуск

1. Установите Python 3.9 или новее.
2. Установите Flask:
   ```
   pip install flask
   ```
3. Запустите сервер из папки `vbank`:
   ```
   python app.py
   ```
4. Откройте в браузере http://127.0.0.1:5000

## Как пользоваться

1. На главной странице откройте вкладку **Открыть счёт**: введите имя, возраст (от 18) и пароль (от 4 символов).
2. В личном кабинете выберите операцию: **Пополнить**, **Снять** или **Перевести**.
3. Чтобы проверить переводы, откройте второй профиль браузера или режим инкогнито, зарегистрируйте второго клиента и отправьте ему деньги по имени.

## API

Все запросы отправляются с телом в формате JSON, ответы тоже JSON. После входа клиент определяется по сессии, поэтому имя в запросах не передаётся.

| Метод | Адрес | Тело запроса | Что делает |
|-------|-------|--------------|------------|
| POST | `/api/register` | `name`, `age`, `password` | Открывает счёт и сразу входит |
| POST | `/api/login` | `name`, `password` | Вход |
| POST | `/api/logout` | — | Выход |
| GET | `/api/me` | — | Данные текущего клиента |
| POST | `/api/deposit` | `amount` | Пополнение |
| POST | `/api/withdraw` | `amount`, `password` | Снятие |
| POST | `/api/transfer` | `to`, `amount`, `password` | Перевод другому клиенту |

Успешный ответ: `{"ok": true, "name": "...", "age": 20, "balance": 100.0, "history": [...]}`.
Ошибка: `{"ok": false, "error": "Недостаточно средств"}` с кодом 400, 401, 404 или 409.

## Класс Client (`modules/bank_module.py`)

| Метод | Описание |
|-------|----------|
| `put_money(amount)` | Пополнить счёт |
| `get_money(amount, password)` | Снять деньги |
| `get_balance()` | Узнать баланс |
| `change_age(new_age)` | Сменить возраст |
| `change_password(last_password, new_password)` | Сменить пароль |
| `change_name(new_name, password)` | Сменить имя |

Функция `transfer(client_1, client_2, amount, password)` переводит деньги от `client_1` к `client_2`. Пароль нужен отправителя.

Методы возвращают строки: `'Completed'`, `'Wrong password'`, `'Not enough money'`, `'Wrong amount'`. В `app.py` они переводятся на русский для интерфейса.
